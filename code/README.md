# Analysis and figures

Run the commands in the [main README](../README.md) in order. `download.py` checks or retrieves the frozen Medicare workbooks, `extract.py` extracts their analysis sheets, `analyze.py` generates aggregate results and `validate.py` performs independent numeric checks. `figures.py` renders main and supplementary plots. `draw_figure1.py` through `draw_figure3.py` export the revised main figures.
