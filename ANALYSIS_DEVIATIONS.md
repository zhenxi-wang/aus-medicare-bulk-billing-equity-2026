# Protocol clarifications before manuscript drafting

12 November 2026: Official explanatory notes establish that these Departmental quarterly workbooks use **claim-processing date**, whereas the AIHW dashboard uses service date. The study uses the Departmental files only; timing and lags will be stated explicitly. The final period is April–June 2026, not a June-only snapshot. This clarification precedes running any alternative main model.

Published out-of-hospital cost metrics have different denominators from all-setting service counts. The C/D/E pooled bulk-billing rate can be computed exactly, but pooled out-of-hospital costs cannot be recovered exactly from the available columns. Cost results will therefore remain separated by B/C/D/E. No approximate weighted pooled cost will be presented.

SEIFA categories are used as published, with the workbook's warning about longitudinal comparability; no claim of following fixed individuals or measuring individual income is made. Quintile results are descriptive same-quarter comparisons.

The primary and all eight prespecified model specifications were run after the protocol was saved. No choice was made according to P-values. No inferential subgroup testing was added.

Technical verification corrected the HAC implementation to use actual calendar-quarter distances rather than adjacent retained rows across excluded implementation quarters. The prespecified lag lengths, model and point estimates were unchanged; the primary SE changed from 0.16051 to 0.16100 pp and the rounded upper CI from −1.69 to −1.68 pp. All sensitivity intervals were regenerated. This was a covariance implementation correction, not a significance-driven specification choice.
